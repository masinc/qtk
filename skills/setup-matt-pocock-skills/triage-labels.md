# トリアージラベル

スキル群は 5 つの標準トリアージロールの言葉で語ります。このファイルは、それらのロールをこのリポジトリのイシュートラッカーで実際に使われるラベル文字列に対応付けます。

| mattpocock/skills のラベル | 当トラッカーのラベル | 意味                                   |
| -------------------------- | -------------------- | -------------------------------------- |
| `needs-triage`             | `needs-triage`       | メンテナがこのイシューを評価する必要がある |
| `needs-info`               | `needs-info`         | 報告者からの追加情報を待っている           |
| `ready-for-agent`          | `ready-for-agent`    | 完全に仕様化されており、AFK エージェントの準備ができている |
| `ready-for-human`          | `ready-for-human`    | 人間による実装が必要                     |
| `wontfix`                  | `wontfix`            | 対応しない                             |

スキルがロールに言及したとき (例:「AFK 対応のトリアージラベルを適用する」) は、この表の対応するラベル文字列を使用します。

右側の列を、実際に使っている語彙に合わせて編集してください。
