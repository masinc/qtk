## Context

当初、npm パッケージ名は素の `qtk` で公開する計画だった。design.md では「`bunx qtk` で実行できる素の名前」を採用し、`@masinc/qtk` (スコープ付き) は `bunx @masinc/qtk` が長く頻繁に呼ぶスキル群には不向きとして却下していた。

しかし実際の `npm publish` で 403 Forbidden が発生:
```
Package name too similar to existing packages q,qs,htm,ink,gts,st,mqtt,ftp;
try renaming your package to '@masinc/qtk' and publishing with 'npm publish --access=public' instead
```

npm は既存パッケージ (q, qs, htm, ink, gts, st, mqtt, ftp) と名前が類似しているとして `qtk` の公開を拒否した。

## Decision

npm パッケージ名を **`@masinc/qtk`** (スコープ付き) に変更する。

- `package.json` の `name` を `@masinc/qtk` に変更
- `npm publish --access public` (スコープ付きパッケージはデフォルト private のため public 指定が必要)
- bin 名は `qtk` のまま維持 (グローバルインストール時は `qtk` コマンドで呼べる)
- 実行は `bunx @masinc/qtk` となる (スキル群のコマンド例も更新済み)

併せて、npm が `cli.ts` を bin として無効扱い (`.ts` 拡張子を拒否) して publish から削除する問題にも対応:
- `bun build` で `dist/cli.js` を生成し bin に指定
- `prepublishOnly` スクリプトで publish 前に自動ビルド

## Consequences

**ポジティブ**:
- npm に公開可能になった (類似名前拒否を回避)
- スコープ付きで名前空間が明確 (@masinc 配下)
- `dist/cli.js` を bin にすることで npm の bin 検証をクリア

**ネガティブ**:
- `bunx @masinc/qtk` が `bunx qtk` より長い。スキル群のコマンド例を全て更新する必要があった (50箇所)
- スコープ付きパッケージは `--access public` 指定が必須 (初回公開時)

**リスク**:
- グローバルインストール (`npm i -g @masinc/qtk`) 時の bin 名 `qtk` の衝突可能性。他パッケージが `qtk` bin を提供している場合、後からインストールした方が勝つ。動作確認が必要 (Issue #0012)
